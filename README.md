# RMSAQA — ICASSP 2027 Grand Challenge

Website for **RMSAQA: Real-world Multi-hop Spatial Audio Question Answering Challenge**, an ICASSP 2027 Grand Challenge for grounded spatial audio reasoning in smart homes.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The Vite `base` is set to `/rmsaqa/`, so the generated `dist/` directory is ready for the project's GitHub Pages URL:

<https://sprat-lab.github.io/rmsaqa/>

## Updating pending information

Official dates, links, organizers, and contact details are intentionally marked as **Coming soon**. Update the corresponding arrays and timeline content in `src/App.tsx` once the challenge information is finalized.
